// doctrine

Three properties hold across the family.

Read-only by default.

Skills diagnose and prescribe fixes. They do not rewrite code unless you ask.

Scoped, not overlapping.

Each critic states what it does not cover and names the sibling that covers it.

Purpose-gated, not style-gated.

Technique is allowed when it has a reason. Technique without purpose becomes a finding.

// live bridges

Authorized dynamic testing, delegated.

Strix

Protocol B can delegate dynamic app scans to an installed Strix agent inside its own Docker sandbox. Validated PoCs outrank static reasoning.

Wallbreaker

For AI-bearing targets, Protocol B delegates LLM jailbreak testing to Wallbreaker. Own models only, reliability validated before severity.
